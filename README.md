## XYZ Bank Application – Manual Testing

## Project Overview
XYZ Bank is a web-based banking application tested to verify its functionality, usability, and reliability.

## Application Details
- **Application:** XYZ Bank
- **Application Type:** Web Application
- **Testing Approach:** Manual Testing

## Testing Scope
Manual testing was performed to verify banking functionalities, user navigation, customer management, account operations, 
deposits, withdrawals, and transaction-related features.

## Modules Tested
- Home Page
- Customer Login
- Transaction
- Deposit
- Withdrawal
- Bank Manager Login
- Add Customers
- Open Account
- Customers

## Testing Types
- Functional Testing
- Regression Testing
- Integration Testing
- System Testing

## Test Cases
A total of **133 test cases** were designed and executed across the application modules.
